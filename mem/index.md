# Project Memory

## Core
Iron Lifting Club app. PT-BR only. Mobile-first (max 390px). Light theme only (no dark mode).
Primary #1400FF, bg #F4F5FA. Barlow Condensed headings/numbers, DM Sans body.
Spartan logo uses original colors, never convert to primary blue.

## Memories
- [Brand Identity](mem://style/brand-identity) — Visual identity, colors (#1400FF, #F4F5FA) and typography (Barlow Condensed, DM Sans)
- [Logo Handling](mem://style/logo-handling) — Spartan helmet logo must use original colors, never royal blue
- [App Structure](mem://features/app-structure) — Mobile-first fitness app with 5 main tabs
- [Ranking System](mem://features/ranking-system) — Ranking based on XP and workouts, visual podium, current user highlight
- [Technical Requirements](mem://constraints/technical-requirements) — PT-BR only, max 390px width, no dark mode
- [Notificações Push](mem://features/push-notifications) — Web Push VAPID, lembrete de aula 30 min antes (cron) e mensagem direta da equipe
